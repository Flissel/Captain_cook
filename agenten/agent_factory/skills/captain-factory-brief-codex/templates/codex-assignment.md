# Codex Assignment

- Invocation and candidate bindings: job, correlation, subject version, attempt,
  released skill digest, input digest, lease, and idempotency key.
- Work: goal, measurable outcome, dependency-ready node, worktree, allowed paths,
  architecture constraints, required test IDs, and documentation sources.
- Limits: released tool policy, model and budget limits, sandbox, forbidden effects.
- Evidence: code, tests, manifests, content digests, commands, and failures.
- Completion: return the typed build artifact; stop outside the lease.
