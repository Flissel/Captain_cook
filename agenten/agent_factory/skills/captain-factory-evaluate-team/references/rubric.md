# Evaluation Rubric

Evaluate in order: invocation bindings and redaction; deterministic accepted
assertions and private holdouts; build/test/integration/typed n8n evidence;
output relevance and quality; AutoGen conversation, handoffs, memory,
termination, and recovery; then cost, latency, and repeat stability. A model
judge is optional only after deterministic gates. Record each outcome and its
evidence reference; never change the candidate or released criteria.
