# Captain-private benchmark catalog

## Completed scope

- [x] Remove concrete benchmark cases and expected predicates from the
  worker-visible `FactoryInputDocumentV2` contract.
- [x] Publish only the fixed category/count/dimension/ruleset policy and stable
  source keys derived from acceptance outcomes, document and agent real cases,
  integration success/failure/tool rules, authority boundaries, security rules,
  and stop conditions.
- [x] Generate exactly fifteen deterministic, non-vacuous cases from a private
  seed without persisting or printing the seed.
- [x] Compile private bodies only through an exact input-SHA and policy-SHA
  catalog binding; expose only content-addressed holdout references publicly.
- [x] Require production to single-open a digest-pinned catalog from a dedicated
  root outside Git repositories/worktrees before Gateway schema or provider
  effects.
- [x] Add an idempotent local init command with explicit manifest-path rotation.
- [x] Accept deterministic seed material only from ephemeral stdin; the default
  is in-process OS randomness and neither mode persists, logs, or forwards it.
- [x] Apply category-specific source-grounded transformations and use only the
  exact human roles and stop reasons declared by each canonical input.
- [x] Validate all fifteen definitions and mappings before one atomic holdout
  batch write; a late invalid source leaves no partial suite.
- [x] Bind manifest SHA and canonical suite identity into production attestation
  and invalidate readiness on catalog rotation or mutation.
- [x] Prove all three canonical demo inputs admit, compile, and form balanced
  private suites without concrete private data in their source bytes.

## Non-claims

- [ ] No provider, n8n, database, Minibook, or live benchmark was executed by
  this offline change.
- [ ] Generated synthetic cases remain release-validation fixtures; they are
  not evidence of regulated-domain accuracy or production fitness.
- [ ] Operators still have to create and provision the local private catalog
  and bind its path and SHA-256 in the production environment.
